# Technology logos

These SVGs are unmodified copies of the `original` variants from
[Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons).
Each file was downloaded from `icons/<name>/<name>-original.svg` and renamed
to `<name>.svg`. They are bundled locally through Vite, with no runtime CDN requests.

Devicon is a community-maintained collection of technology brand artwork,
not an official endorsement by the brands. Its MIT license is included in
`LICENSE.devicon`. Brand names and logos belong to their respective owners.

General disciplines such as SQL, debugging, and system integration use Lucide
interface icons rather than assigning an unrelated vendor's logo to them.
